# Hospital Regional de Huamanga

**Nombre:** Jhony Alberto Sulca Mendoza  
**Curso:** Arquitectura de Software  
**Descripción:** Sistema Web para la Gestión de Citas Médicas y Entrega de Resultados  

---

Bienvenido al repositorio documental y arquitectónico del sistema. Este proyecto consolida el diseño, las decisiones y las mejoras estructurales para la modernización de la atención ambulatoria.

## Estructura del Proyecto

La documentación y definiciones arquitectónicas están organizadas en los siguientes directorios:

- 📂 **[Análisis del Sistema](./analisis_del_sistema/)**: Contiene la definición de actores, historias de usuario, requerimientos funcionales y no funcionales, restricciones, drivers y decisiones arquitectónicas.
- 📂 **[Arquitectura](./arquitectura/)**: Contiene la definición formal en diagramas (Mermaid) del estilo arquitectónico, el enfoque (Clean Architecture + CQRS) y la arquitectura inicial del sistema.

## Resumen del Proyecto
El sistema está diseñado para soportar **alta concurrencia**, garantizar la **seguridad clínica** (evitando cruces de citas y diagnósticos erróneos) y cumplir con la legislación de **protección de datos sensibles**.
