# Restricciones (Fuera de Alcance y Limitaciones)

| Tipo | Restricción / Exclusión |
|---|---|
| **Funcional** | No se desarrollará una Historia Clínica Electrónica (HCE) completa. |
| **Integración** | No hay integración directa en tiempo real con sistemas del MINSA (HIS, SIS, RENIEC) en esta fase. |
| **Clínico / IA** | No se usarán algoritmos de IA para diagnósticos automáticos ni predicción de inasistencias. |
| **Imágenes (PACS)** | No se implementará un sistema PACS/VNA completo ni renderizado 3D de DICOM pesados. Solo PDF e imágenes web optimizadas (JPEG/WebP). |
| **Financiero** | No incluye facturación electrónica ni pasarelas de pago. |
| **Plataforma** | Sistema puramente web responsive; no se desarrollarán aplicaciones móviles nativas (Android/iOS). |
