# Historias de usuario

| ID | Historia de usuario |
|---|---|
| HU01 | Como paciente, quiero consultar disponibilidad por especialidad, profesional y fecha, para elegir una cita conveniente. |
| HU02 | Como paciente, quiero reservar, reprogramar o cancelar citas, para organizar mi atención médica. |
| HU03 | Como paciente, quiero consultar y descargar mis resultados diagnósticos publicados, para acceder a ellos sin acudir al hospital solo por documentos. |
| HU04 | Como agente de admisión, quiero registrar y buscar pacientes, para brindar atención asistida a quienes no pueden gestionar citas por internet. |
| HU05 | Como personal de laboratorio, quiero registrar resultados asociados a una solicitud y paciente, para enviarlos a revisión profesional. |
| HU06 | Como personal de imágenes, quiero asociar informes PDF e imágenes representativas a estudios diagnósticos, para completar el registro del estudio. |
| HU07 | Como profesional validador, quiero aprobar o rechazar informes antes de su publicación, para garantizar que solo se publiquen resultados revisados. |
| HU08 | Como administrador, quiero gestionar especialidades, profesionales, horarios, roles y permisos, para mantener los servicios de la plataforma. |
| HU09 | Como paciente, quiero recibir avisos cuando cambie una cita o se publique un resultado, para estar informado oportunamente. |
| HU10 | Como representante autorizado, quiero consultar citas y resultados del paciente representado, para actuar en su nombre sin compartir credenciales. |
| HU11 | Como paciente o responsable legal, quiero solicitar y gestionar una representación autorizada, para que otra persona pueda operar en mi nombre. |
| HU12 | Como paciente o responsable legal, quiero revocar una autorización de representación, para impedir que esa persona siga accediendo a mi información. |
| HU13 | Como auditor autorizado, quiero consultar los registros de accesos y operaciones sobre información clínica, para verificar trazabilidad. |

> **Nota:** La HU03 original del docx y la HU11 del docx eran redundantes (ambas sobre descargar resultados). Se unificaron en HU03.
